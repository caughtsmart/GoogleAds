### Better fix: campaign-specific conversion goals (UI only)

The underlying problem is that Demand Gen has no conversion signal
because the YouTube actions were made account-wide Secondary. Google
supports **campaign-level conversion goals**, which solves this properly:

- Demand Gen uses the YouTube engagement actions as ITS primary goal →
  bidding signal restored, delivery and CPM should recover.
- PMAX / Search keep purchase-only goals → no pollution of value bidding.

This is exactly the configuration these two campaigns want, and it is
strictly better than a bidding-strategy change. There is no Windsor
action for conversion goals, so it must be done in the Ads UI:

> Campaign "Demand Gen Brand Awareness" → Settings → Goals → "Use
> campaign-specific conversion goals" → set "YouTube channel
> subscriptions" (and "YouTube follow-on views") as primary for this
> campaign only.

If Graham prefers not to do this, the fallback is to accept the reduced
reach — spend is self-limiting at ~£12-20/day, so the cost of inaction is
low; it simply buys less awareness per pound than it did.
